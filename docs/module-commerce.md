# Module — Prix & commerce

## Intention

Travailler les calculs commerciaux du CAP groupement 2 à partir de situations simples de restauration.

Le module distingue d'abord :
- coût ;
- prix de vente ;
- remise ;
- marge simple.

La taxe n'est utilisée que dans un exercice où le taux est explicitement fourni.

## Manipulation

Une commande de menus à 8,50 € est recalculée quand l'élève change :
- le nombre de menus ;
- le taux de remise.

L'interface affiche :
- sous-total ;
- remise ;
- montant à payer ;
- coût estimé ;
- marge simple après remise.

## Méthode proposée

1. quantité × prix unitaire ;
2. calculer la remise ;
3. retirer la remise ;
4. pour la marge simple de l'exercice : prix de vente − coût.

## Entraînement V1

1. montant pour 6 menus à 8,50 € ;
2. prix après remise de 10 % ;
3. marge simple entre coût et prix ;
4. montant d'une taxe avec taux fourni.

## Prudence pédagogique

Les règles fiscales réelles varient selon les situations. Le module ne demande pas de mémoriser un taux légal ; lorsqu'un taux est utilisé, il est donné dans l'énoncé.

Le feedback reste local dans cette V1.
