# Module — Données & statistiques

## Intention

Apprendre à lire des données avant de calculer dessus.

Le module part de trois usages PSR :
- comparer des ventes ;
- suivre des quantités de stock ;
- repérer les choix les plus fréquents.

## Manipulation

Un graphique présente le nombre de menus servis du lundi au vendredi.

L'élève fait varier la valeur du vendredi et observe immédiatement :
- le graphique ;
- le total ;
- le maximum ;
- le minimum ;
- la moyenne.

L'objectif est de voir qu'une moyenne dépend de toutes les valeurs et qu'elle résume une série sans remplacer la lecture du détail.

## Méthode proposée

1. lire le titre, les unités et les valeurs ;
2. comparer les nombres ;
3. si on demande une moyenne, additionner les valeurs puis diviser par leur nombre.

## Vocabulaire

Commencer avec : plus grand, plus petit, total, moyenne, « revient souvent ».

Introduire ensuite : fréquence, série de données, valeur la plus fréquente.

## Entraînement V1

1. repérer le jour avec le plus de menus ;
2. calculer la moyenne de 20, 30 et 40 ;
3. transformer 12 sur 40 en fréquence de 30 % ;
4. repérer la valeur la plus fréquente dans une courte série.

Le feedback reste local dans cette V1.

## Suite possible

- tableaux plus complets ;
- diagrammes en barres et circulaires ;
- étendue ;
- médiane si utile dans le cadre du programme ;
- lecture critique de graphiques.
