# Module — Durées

## Intention

Faire comprendre les heures et les durées à partir de situations PSR avant d'introduire des procédures formelles.

Le module n'est pas un chapitre abstrait sur le système sexagésimal. Il part de trois besoins métier :
- prévoir une fin de cuisson ;
- savoir quand commencer avant le service ;
- mesurer la durée d'une tâche.

## Vocabulaire

Commencer avec : heure, minute, début, fin, durée, avant, après.

Introduire ensuite : conversion, système sexagésimal si nécessaire. Ne pas demander ce vocabulaire avant que les situations soient comprises.

## Manipulation

Deux curseurs permettent de modifier :
- l'heure de départ ;
- la durée.

L'heure de fin est recalculée immédiatement.

Point clé : **1 h = 60 min**, pas 100 min.

## Méthode proposée

Pour ajouter une durée :
1. aller jusqu'à l'heure ronde ;
2. compter les minutes utilisées ;
3. ajouter les minutes restantes.

Exemple : 9 h 35 + 50 min = 10 h 25.

## Entraînement V1

1. ajouter 50 min à 9 h 35 ;
2. retirer 35 min à 11 h 45 ;
3. calculer la durée entre 10 h 15 et 12 h ;
4. convertir 1 h 30 en minutes.

Le feedback est immédiat mais n'est pas envoyé au serveur dans cette V1.

## Suite possible

- durées dépassant plusieurs heures ;
- planning de production avec plusieurs tâches ;
- choix de l'ordre des tâches ;
- conversions heure décimale ↔ heure/minutes quand cela devient utile.
