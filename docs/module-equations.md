# Module — Équations

## Intention

Faire comprendre l'équation comme une recherche de nombre inconnu, pas comme une manipulation abstraite de lettres.

La lettre **x** est présentée seulement après la situation :
- plusieurs lots donnent un total connu ;
- un prix a été augmenté d'une somme connue ;
- plusieurs produits identiques donnent un montant total.

## Manipulation

Le module utilise l'égalité :

**3 × x = 24**

L'élève fait varier x avec un curseur. Les deux côtés de l'égalité sont affichés en parallèle et l'interface indique quand l'égalité est équilibrée.

## Idée clé

Chercher x revient à annuler l'opération qui a été faite avec x.

Exemples :
- 3 × x = 24 → 24 ÷ 3 = 8 ;
- x + 7 = 19 → 19 − 7 = 12 ;
- x − 4 = 11 → 11 + 4 = 15.

Le vocabulaire « opération inverse » vient après les exemples.

## Entraînement V1

1. 3 × x = 24 ;
2. x + 7 = 19 ;
3. prix unitaire de 4 menus coûtant 36 € ;
4. x − 4 = 11.

Le feedback reste local dans cette V1.

## Suite possible

- équations avec décimaux ;
- vérification systématique par remplacement ;
- situations avec plusieurs étapes ;
- lien avec les fonctions.
