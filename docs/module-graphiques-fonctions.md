# Module — Graphiques & fonctions

## Intention

Faire voir qu'une quantité peut dépendre d'une autre avant d'introduire le mot « fonction ».

Situation centrale :
- chaque menu coûte 8 € ;
- le nombre de menus vendus varie ;
- le montant encaissé varie avec lui.

## Manipulation

Un curseur règle le nombre de menus entre 0 et 20.

L'interface montre simultanément :
- le nombre de menus ;
- le calcul × 8 € ;
- le montant total ;
- un point mobile sur un graphique ;
- la relation **y = 8 × x**.

## Lecture du graphique

1. identifier ce que représente l'axe horizontal ;
2. identifier ce que représente l'axe vertical et son unité ;
3. partir d'une valeur sur un axe et lire la valeur correspondante sur l'autre.

## Vocabulaire

Commencer avec : quantité, dépend de, augmente, axe horizontal, axe vertical.

Introduire ensuite : fonction, x, y, image, relation.

## Entraînement V1

1. montant pour 6 menus à 8 € ;
2. lire y pour x = 10 dans y = 8 × x ;
3. retrouver le nombre de menus pour 96 € ;
4. comprendre que doubler le nombre de menus double le montant à prix fixe.

Le feedback reste local dans cette V1.

## Suite possible

- tableaux de valeurs ;
- fonctions linéaires et affines ;
- situations avec coût fixe + coût variable ;
- comparaison de deux tarifs ;
- lecture d'intersections.
