# Module — Pourcentages

## Intention

Faire comprendre le pourcentage comme une **part sur 100** avant d'introduire des procédures de calcul.

Le module part de situations PSR :
- répartition des menus ;
- réductions de prix ;
- part d'un stock utilisé.

Le repère visuel central est une grille de 100 cases. L'élève déplace un curseur et voit la part colorée ainsi que quelques écritures équivalentes.

## Repères à installer

- 100 % = tout ;
- 50 % = la moitié = 1/2 = 2/4 ;
- 25 % = un quart = 1/4 ;
- 75 % = trois quarts = 3/4.

Le vocabulaire « pourcentage » vient avec l'idée « sur 100 ».

## Méthode proposée

1. repérer le total ;
2. comprendre la part demandée ;
3. calculer cette part ;
4. vérifier si le résultat est cohérent.

## Entraînement V1

1. 25 % de 40 produits ;
2. réduction de 50 % sur 18 € ;
3. réduction de 10 % sur 20 € ;
4. 30 commandes sur 50 exprimées en pourcentage.

Le feedback reste local dans cette V1.

## Suite possible

- augmentations et diminutions ;
- taux d'évolution ;
- TVA et remises plus réalistes ;
- lien avec fréquence statistique ;
- comparaison fraction / décimal / pourcentage.
