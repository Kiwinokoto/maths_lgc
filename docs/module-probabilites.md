# Module — Probabilités

## Intention

Présenter les probabilités comme une manière de raisonner sur le hasard, pas comme un chapitre abstrait.

Le module suit les attendus CAP :
- expérience aléatoire simple ;
- événement ;
- probabilité entre 0 et 1 ;
- événement impossible et certain ;
- événement contraire ;
- lien entre fréquence observée et probabilité ;
- stabilisation des fréquences par simulation.

## Situation centrale

Un lot contient 10 tickets, dont 3 violets.

La probabilité théorique de tirer un violet est :
- 3 cas favorables ;
- 10 cas possibles ;
- 3/10 = 0,3 = 30 %.

Chaque tirage est fait avec remise.

## Simulation

L'élève peut lancer :
- 1 tirage ;
- 20 tirages ;
- 100 tirages.

L'interface affiche :
- nombre total de tirages ;
- nombre de violets ;
- fréquence observée ;
- repère fixe de probabilité théorique à 30 % ;
- historique des derniers tirages.

L'objectif est de voir que :
- sur peu d'essais, la fréquence peut être loin de 30 % ;
- quand le nombre d'essais augmente, la fréquence tend à se rapprocher de 30 % ;
- elle n'a pas besoin d'être exactement égale à 30 %.

## Entraînement V1

1. calculer 2 cas favorables sur 10 ;
2. probabilité d'un événement impossible ;
3. événement contraire de 30 % ;
4. interpréter une fréquence de 40 % observée sur seulement 10 essais.

Le feedback reste local dans cette V1.
