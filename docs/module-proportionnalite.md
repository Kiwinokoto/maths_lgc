# Module — Recettes & proportionnalité

## Intention

Faire voir la proportionnalité avant de la nommer.

L'élève manipule d'abord une fiche technique :
- la recette de base correspond à 10 portions ;
- un curseur change le nombre de portions ;
- toutes les quantités évoluent avec le même multiplicateur.

Quand ce comportement est compris, introduire le mot **proportionnalité** et le terme **coefficient**.

## Situations PSR

- adapter une recette ;
- prévoir une quantité de boisson ;
- adapter une production de barquettes.

Ces situations montrent le même raisonnement avec des objets différents.

## Idée clé

Si le nombre de portions est multiplié par un nombre, chaque quantité est multipliée par ce même nombre.

Exemple :
- 5 portions → 15 portions : × 3 ;
- 400 g de riz → 1 200 g : × 3.

## Méthode proposée

1. comparer le nouveau nombre de portions au nombre de départ ;
2. calculer le multiplicateur ;
3. appliquer ce même multiplicateur à chaque quantité.

Le vocabulaire « coefficient de proportionnalité » vient après cette compréhension.

## Entraînement V1

1. 400 g pour 5 portions → 15 portions ;
2. 2 L pour 8 personnes → 20 personnes ;
3. 750 g pour 6 portions → 18 portions ;
4. trouver le coefficient pour passer de 10 à 25 portions.

Le feedback est immédiat mais n'est pas envoyé au serveur dans cette V1.
